# منظومة الذكاء الاصطناعي الفضائية لتحليل وحرائق المركبات ومحاكاة اللهب
## NASA Space Fire AI System (4 Multi-Agents Architecture)

منظومة ذكاء اصطناعي متكاملة للمركبات الفضائية ومحطة الفضاء الدولية (ISS)، تدعم التخصيص الكامل والديناميكي للمتغيرات وربطها السلس بالواجهات الأمامية (Frontend).

---

## 🛰️ الوكلاء الأربعة (The 4 Intelligent Agents)

### 1. العميل 1: متنبئ خطر الحريق (Fire Risk & Severity Predictor)
- **الوظيفة:** تحليل بيانات ناسا وتجارب الاحتراق والتنبؤ بـ:
  1. **نسبة حدوث الحريق** (`fire_probability_percent`: 0% - 100%).
  2. **درجة الخطورة** (`hazard_level`: آمن، متوسط، مرتفع، حرج).
  3. **وصف الحالة بالذكاء الاصطناعي** (`description`: تشخيص فيزيائي مسبب).
- **المدخلات:** متغيرات ديناميكية لحالة المركبة الفضائية تحددها أنت وتتحكم في إتاحتها للمستخدم.
- **الـ Endpoint:** `POST /api/predict/agent1`

### 2. العميل 2: مساعد طوارئ وأعطال الحريق (Safety Incident Chatbot)
- **الوظيفة:** يستقبل وصف المستخدم لحريق صغير أو عطل حراري في المركبة ويقوم بـ:
  - تشخيص **سبب المشكلة أو العطل الفني بدقة** (تفريغ كهربائي، انفلات حراري لبطاريات الليثيوم، احتكاك محامل التهوية، تسريب أكسجين).
  - تحديد النظام الفرعي المتأثر.
  - تقديم **خطوات السلامة والإخماد الفورية** المعتمدة من بروتوكولات طوارئ ناسا (NASA Fire Response Protocol).
- **الـ Endpoint:** `POST /api/chat/agent2`

### 3. العميل 3: راصد محطة الفضاء الدولية اللحظي (ISS Live Telemetry Monitor)
- **الوظيفة:** يعمل **تلقائياً وبشكل مستقل بالكامل دون أي إدخال من المستخدم**.
- مربوط ببث حي لتيليميتري محطة الفضاء الدولية (ISS ECLSS Telemetry) ومتجدد **كل ثانية (1-Second Tick)** عبر تقنية Server-Sent Events (SSE).
- يتنبأ بنسبة خطر الحريق اللحظية ودرجة الخطورة ويعرض الحالة وخطوط الطول والعرض والسرعة المدارية والارتفاع.
- **الـ Endpoint:**
  - البث المباشر: `GET /api/stream/agent3` (EventSource)
  - لقطة مفردة: `GET /api/iss/current`

### 4. العميل 4: محاكي اللهب البصري بالذكاء الاصطناعي (AI Flame Visual Simulation)
- **الوظيفة:** محاكاة حقيقية وليست رسوماً متحركة مزيفة (`Not a Fake Animation`).
- مبنية على خوارزميات ونماذج فيزياء الاحتراق في انعدام الجاذبية الناتجة عن تجارب ناسا (CIR, BASS, ACME, FLEX):
  - **في انعدام الجاذبية ($0g$ في ISS):** ينعدم الحمل الحراري الطافي؛ يتحول اللهب إلى **كرة متناظرة (Spherical Diffusion Flame)** بنسبة استطالة $1.0$، وينعدم الاهتزاز (0 Hz)، ويهيمن الانبعاث الأزرق النقي لراديكالات $CH^*$ و $C_2^*$.
  - **في الجاذبية الأرضية ($1g$):** قوى الطفو تشد اللهب لأعلى بشكل **دمعة متطاولة (Buoyant Teardrop)** مع ظهور اهتزاز ديناميكي (Kelvin-Helmholtz Instabilities) وتردد تذبذب ~10-15 Hz وإشعاع سخام أصفر متوهج.
- **تحديث فوري لايف:** بمجرد تحريك أي شريط أو تغيير المادة (PMMA, Polyethylene, Nomex, Heptane, Methane, Cotton) يتغير شكل اللهب وألوانه ودرجة حرارته لحظياً.
- **الـ Endpoint:** `POST /api/simulate/agent4`

## ⚙️ نظام إدارة الخانات والمتغيرات الديناميكية (Dynamic Variable Architecture)

أحد أهم ركائز المنظومة هو أنك لست مقيداً بأي قوائم ثابتة:
1. **إضافة أي متغير جديد بحرية تامة:**
   - من شاشة `تخصيص المتغيرات وربط الفرونت`، يمكنك إضافة أي متغير (مثل: `wire_temperature_c`, `coolant_pressure`, `co2_percent`).
2. **التحكم في إتاحة المتغير للمستخدم للتنبؤ:**
   - لكل متغير زر تبديل (Toggle) لتحديد ما إذا كان المستخدم النهائي في الفرونت إند يستطيع إدخاله أثناء التنبؤ أم لا.
3. **التأثير الرياضي الحقيقي في الـ AI:**
   - كل متغير يضاف للسيستم يدخل في تدريب خوارزمية **غابات القرار العشوائية (Dynamic Random Forest Ensemble)**.
   - يعالج السيستم غياب بعض المتغيرات في بعض الدفعات بسلاسة (Missing-value imputation & feature isolation).
4. **ربط الفرونت إند بضغطة زر:**
   - لكل خانة، يولد السيستم تلقائياً:
     - كود الـ HTML الجاهز للخانة (`<input ...>`).
     - معرّف الـ JSON المطلوب إرساله للـ Backend.
     - كود جافاسكريبت `fetch()` كامل جاهز للنسخ واللصق في مشروع الفرونت القادم!

## 📊 إدخال البيانات وتدريب الـ AI (Data Ingestion & Training)

- يتيح لك السيستم رفع دفعات بيانات مختلفة المتغيرات (مثال: دفعة تحتوي على $O_2$ و $CO_2$ فقط، ودفعة أخرى تحتوي على $O_2$ وحرارة الأسلاك).
- يقوم السيستم بدمج المتغيرات تلقائياً، وتحديث شجرة القرارات، واحتساب **أوزان الأهمية (Feature Importance Scores)** لكل متغير لتتأكد من أنه مؤثر رياضياً في القرار.

## 🚀 تشغيل المنظومة (Running the System)

### الطريقة السريعة:
1. انقر نقراً مزدوجاً على الملف:
   ```cmd
   start_server.bat
   ```
   أو من خلال PowerShell:
   ```powershell
   .\start_server.ps1
   ```
2. افتح المتصفح على الرابط:
   ```
   http://localhost:8000
   ```
